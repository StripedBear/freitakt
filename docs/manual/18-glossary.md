# Glossary
<!--blurb: Short definitions of every term and abbreviation used on the screen.-->

## Terms

| Term | Meaning |
| --- | --- |
| **ACCENT / ACC** | a louder step; with [[OCT+]] held, tap a step to toggle it. |
| **ACID** | the 303-style bass model; at most two tracks. |
| **ACCEL** | knob acceleration (MENU). |
| **ARP** | the button (a tap: the ARP pages, again: page 2; ARP + black keys: solo; KEYS on, ARP + a white key: live retrigger); see ARP1, ARP2. |
| **ARP1** | the arpeggiator MODE (pitched models): the step's (or held key's) note spread by CHORD over RANGE octaves in DIR's order, a note every RATE. Older projects' ARP. |
| **ARP2** | the arpeggiator MODE over the keys held in KEYS (pitched models): the held notes by pitch in DIR's order over RANGE octaves, a note every RATE; on a step, as ARP1. |
| **BANK** | 16 steps; a track has up to four. |
| **BDTRX... SHTRX** | the TRX models of the MD bank (see Sounds). |
| **CHORD** | the polyphonic chord model (up to four notes, one chord at a time over all tracks); also the ARP page's knob for ARP1's notes. |
| **CHOKE** | choke group 1 to 4: hits cut others in the group. |
| **CLK** | clock source: INT, USB, TRS, BLE, LINK (the menu's CLOCK). |
| **COMP** | the compressor. **GHOST** is its handling of a muted source (MUTE, KEEP, HIDE). |
| **DEST** | the LFO routing page: four slots of source, destination and depth. |
| **DIV** | a track's step division. |
| **E0 to E7** | a model's eight SOUND knobs. |
| **ENV** | the envelope page of the selected track: its DECAY (and ATTACK, or a SAMPL's ATK SUS REL) and the filter's decay FDEC. |
| **FILL** | a step flag; plays only during a fill (hold REC off SEQ). |
| **FM-Link** | two FM-1s in time over Bluetooth. |
| **GO action** | a TOOLS / PROJECT knob that needs two detents within 1.5 s. |
| **KEYS** | the keys play the selected track chromatically ([[SCL]]). |
| **LOCK** | a per-step value for a knob (parameter lock). |
| **MD / MODERN / CLASSIC** | the three sound banks. |
| **MNOTE** | the MIDI note a track answers to (ROUT NOTE). |
| **MOTION** | recorded knob turns. |
| **NLEN** | note length of ACID, SAMPL and CHORD hits in the track's steps (1 to 64, INF), SOUND 1's KNOB 3; Model:Cycles' LEN. Not LEN, the track length. |
| **NOTE** | a step's note (C-1 to G9, shown `C#4`); also the track's NOTE, the note a new step gets (SOUND 1's KNOB 2, or ALGORITHM with KEYS off). |
| **PERFORM** | live master effects while [[FX]] is held. |
| **PITCH** | every machine's tuning knob, -24 to +24 semitones (was TUNE). |
| **PRIO** | HIGH or LOW voice priority. |
| **PROB** | a step's probability. |
| **RATCH** | a step's ratchet repeats (1 to 4). |
| **RTRG** | retrig: a track (or locked step) MODE that repeats the hit (or the key held in KEYS) at RATE; see ARP1. KEYS on, ARP held with a white key plays RTRG on that key whatever the MODE (live retrigger). |
| **ROUT** | MIDI-in routing: NOTE, SEL, TRACK (the menu's MIDI ROUTE). |
| **SCL** | the button labelled SEL: a tap KEYS; held + black key 1 to 6 selects a track. |
| **SLIDE / TIE** | legato glide and held note on ACID steps. |
| **SMC-Mixer** | M-VAVE's Bluetooth mixer, used in DAW mode. |
| **SRC** | an LFO slot's source (LFO1 or OFF), or COMP's key track. |
| **KEYS / STEPS** | SEL lit: the keys play the selected track; SEL unlit: the white keys are its steps on every page. |
| **Sheet** | a bank of 16 steps on the white keys (up to 4); on PATTERN and TRACKS chosen with OCT- / OCT+, elsewhere following the playhead while playing. |
| **SYNC** | MIDI clock out (the menu's MIDI SYNC). |
| **MIDI OUT** | the sequencer's notes out, track n on its channel (GLO MIDI OUT: OUT, TnCH). |
| **THRU** | pass MIDI from each input to the other outputs (the menu's MIDI THRU). |
| **THROW** | PERFORM macro that sends the dry mix into the delay and reverb. |
| **USR1 to USR3** | user sample slots, each a set of up to 16 samples. |
| **ATK / SUS / REL** | the SAMPLE model's envelope: fade-in, held level, release (on the ENV page). |
| **CHOP** | SAMPLE PLAY CHOP: the 16 white keys (and a step's NOTE) pick a sample of the set. Also the editor's Chop tool. |
| **CUT** | SAMPLE: ON makes each hit cut the one sounding. |
| **EDITOR** | the web editor (Sound, Presets, Projects, Patterns, Samples). |
| **+FX** | a USER preset that also sets the track's FX when loaded. |
| **HALL** | the third REVERB TYPE: a smooth stereo reverb. |
| **INSERT** | the per-track effect after DIST: SOFT, HARD, FOLD, FUZZ, CRUSH, PHASR, FLANG, CHOR. |
| **LOOP / LOOPI / ONE** | SAMPLE loop modes: OFF, FWD, PING; LOOPI loops until the next hit; ONE plays START to END. |
| **NUDGE** | a step's hit moved early or late, -50 to +50 hundredths of a step. |
| **PERC** | the built-in sample set: 16 drum and percussion samples. |
| **PLAY** | SAMPLE: KEY (the keys play one sample up and down) or CHOP. |
| **QUANT** | where live recording puts a hit: 1/16, 1/8, 1/32 or OFF (the menu's REC QUANT). |
| **REPEAT STEP** | PERFORM: a held white key (F3 to D4) repeats that track's step; D5 to G5 pick the rate. |
| **SET / SLOT** | SAMPLE: SET picks PERC or USR1 to USR3, SLOT one of its samples (`3/16`). |
| **SOLO** | ARP + black keys 1 to 6; TOGGLE or MOMENTARY mode (ARP + F#5). |
| **SRR** | sample rate reduction on a track (INSERT 2/2). |
| **START / END** | SAMPLE: play part of a sample, 0 to 127 over its length. |
| **Copy / paste combos** | SAVE + REC / PLAY copies / pastes the selected track, GLO + REC / PLAY the pattern, step keys held + REC / PLAY a step or a range of steps; no screen, a short message (`COPIED T3`, `PASTED PATTERN`, `COPIED 3-8`). REC + SEL held 5 s clears the track. (There is no step TOOLS screen; the SAVE page TOOLS is something else.) |
| **USER** | the 96 slots for your own presets; each keeps the track's FX. |
| **Write** | in the editor, sends your changes to the FM-1 (user presets, sample sets). |
| **Safe start** | hold SEQ at power-on: loads nothing; USB updates still answer. |

## Panel abbreviations

HOME, EDIT, SEQ, FX, ARP, LFO, ENV, SCL, GLO, SAVE, PLAY, REC, OCT-, OCT+, SELECT, ALGORITHM, PRESETS, MASTER and KNOB 1 to 4 are described under *The panel*. White keys are named by note: F3 to D4 are the six track keys (tracks 1 to 6); F3 to G5 are the 16 step keys.

## Note names on the keys

| Key | Note |
| --- | --- |
| white keys, steps 1 to 16 | F3, G3, A3, B3, C4, D4, E4, F4, G4, A4, B4, C5, D5, E5, F5, G5 |
| black keys | F#3, G#3, A#3, C#4, D#4, F#4, G#4, A#4, C#5, D#5, F#5 |
| PERFORM effects | F#3 REPEAT 1/8, G#3 REPEAT 1/16, A#3 REPEAT 1/32, C#4 REVERSE, D#4 TAPE STOP, F#4 LPF, G#4 HPF, A#4 FREEZE, C#5 OCT UP, D#5 OCT DOWN; white F3 to D4 REPEAT STEP of tracks 1 to 6; D5 E5 F5 G5 its rate 1/4, 1/8, 1/16 (default), 1/32; G4 A4 B4 C5 and F#5 nothing |
| Combos (button held + key) | black 1 to 11 = F#3 G#3 A#3 C#4 D#4 F#4 G#4 A#4 C#5 D#5 F#5; SEL + black 1 to 6 select tracks 1 to 6; SEQ + black 1 to 6 mute them; ARP + black 1 to 6 solo them, ARP + F#5 solo TOGGLE / MOMENTARY; GLO + white 1 to 4 queue patterns A to D (2 or more: a chain, a black key after a white its variation), GLO + black 1 to 8 variations 1 to 8 |
